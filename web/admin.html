Settings

Daily history

Every market day at 16:30 ET the closing chain and the levels from both engines are saved, for backtests. Changes apply from the next run. The VIX and its family (VIX9D, VIX3M, VIX6M, VIX1Y) are always saved.

Fixed engine tickers

Every 15 minutes the engine calculates the tickers in the users' lists. The ones here are always calculated, even if nobody has them in their list (the VIX is already included). Each ticker makes the cycle a few seconds longer.

Calculation engine

By default the engine is on Auto for everyone: Net with the 0DTE expiration and Profile with the rest. Scanner, Compass and Validation always use Profile. Each user can pick one in Model settings.

Actions

Engine cycle

Recalculates every ticker and view now. It takes about 6 minutes; if one is already running, this one starts when it ends.

Daily history

Saves the last closed session if it isn't saved yet. With “redo” it saves it again even if it already exists.

PC history

Upload historial_para_nube.tar.gz to add what the PC collector saved. It is merged in the next cycle; what is already in the cloud is kept.
